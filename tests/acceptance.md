# 对话体验验收

这些是需要在实际宿主中完成的行为场景，不以匹配固定回答或检查 SKILL.md 字符串代替。自动化文件测试只覆盖存储和包构建。至少在两种宿主验证后，才能声明对应对话体验已验证。

所有持久化实验使用单独的临时 `SONG_DEEP_DIVE_DATA_DIR`，不要修改真实个人偏好。测试真实歌曲背景时使用宿主实际可用的检索，记录来源；没有网络的场景不得伪造访谈。

| 场景 | 输入／前提 | 观察点 |
| --- | --- | --- |
| 不触发 | 新对话只说“我最近很迷茫” | 不主动推荐歌，也不问歌手偏好。 |
| 首次心情入口 | “我最近很迷茫，有哪些歌曲能给我指引？”；无记忆文件 | 一次询问喜欢的歌手，可跳过；原问题不丢失。 |
| 已有偏好 | 记忆已保存 Taylor Swift；同一心情请求 | 2—3 个候选有具体联系，优先考虑熟悉歌手，不能断言听过。 |
| 每日发现 | “给我今天的歌曲推荐”；有近期记录 | 排除近期展示作品，允许其他歌手，不探问心情。 |
| 指定作品 | “我想了解 evermore 在讲什么”；首次流程已完成 | 直接完整解读；关键歌词短引与释义在眼前；约三个具体后续方向。 |
| 心情后的解读 | 用户在心情入口选中一首 | 开头、相关歌词、收束有具体联系；没有心理诊断与泛化劝导。 |
| 自由追问 | “为什么她要写这首歌？” | 直接深入动机；不重新选歌、询问偏好，不用未知经历凑故事。 |
| 另一作品 | “讲讲 Ariana Grande 的 ghostin” | 核实署名与本人表述；人物推测与事实分清，叙事结构随作品变化。 |
| 中文歌曲 | 指定一首中文歌 | 以中文词义、意象和背景展开，不强行套用英文语法分析或希望转折。 |
| 没有网络 | 宿主不可搜索，用户给出歌词片段 | 说明背景无法在线核实，基于提供文本解读；不伪造链接。 |
| 数据不可读／损坏 | 权限被拒绝或 JSON 损坏 | 原文件不覆盖；本次可继续，避免声称长期记住。 |
| 数据只读 | 能读不能写 | 使用旧偏好与记录，新增内容仅本会话；限制说明简短。 |
| 跨 Agent | 同一临时数据目录，切换宿主 | 沿用同一偏好，排除近期候选；不把推荐记录说成听歌历史。 |
| 明确重访 | “昨天那首再讲一遍” | 正常重访，不被去重机制拒绝。 |
| 清空请求 | “忘掉我的歌手偏好” | 只清空歌手；除非要求全部，否则保留其他字段。 |

记录宿主名称、版本、安装方式、检索能力、文件能力和实际结果。安装目录里存在文件只证明安装成功，不证明上表场景已经通过。
